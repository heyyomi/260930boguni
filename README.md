# 🎁 추억의 뽑기 상품 수령 관리 시스템

학교 학급 및 축제 부스에서 운영하는 **"추억의 뽑기"** 당첨 상품 수령 현황을 실시간으로 기록하고 관리하는 웹 애플리케이션입니다.  
클라이언트 단독으로 동작하는 SPA(Single Page Application) 형태로 제작되어 **GitHub 푸시 후 Vercel에 별도 백엔드 서버 없이 즉시 무료 배포**할 수 있습니다.

---

## ✨ 핵심 기능

1. **2대의 디벗(태블릿) 동시 접수 지원**
   - **디벗 1호기 / 2호기** 기기 라벨 전환 기능 탑재
   - 학생: 학년(1~3학년) / 반(1~8반) 원터치 선택 + 이름 입력
   - 교직원: 직책(선생님 / 교직원) 2종 분류 + 이름 입력
   - 품목별 실시간 잔여 수량 표시 및 소진 시 자동 마감 처리

2. **교실 메인 전자칠판 대시보드 (교사용)**
   - 대형 전자칠판에 최적화된 고시인성 UI 및 전체화면(Fullscreen) 모드
   - **실시간 대형 당첨 축하 팝업 & 폭죽(Confetti) 연출**: 디벗에서 학생 정보를 새로 입력할 때마다 전자칠판 중앙에 화려한 폭죽과 함께 `[학년/반] [이름] [상품명] 당첨!` 대형 축하 카드가 자동으로 팝업
   - 보안 비밀번호(`43234323`)로 보호되는 은밀한 교사 모드 진입
   - 반별/학년별/상품별 실시간 필터링 및 이름 검색
   - 엑셀(CSV) 다운로드 및 인쇄(Print) 지원
   - 대시보드 내 [당첨 연출 테스트] 버튼으로 사전 시연 가능

3. **구글 시트(GAS) 실시간 연동 (서버리스 DB)**
   - 구글 스프레드시트를 무료 데이터베이스로 활용 (`doGet`, `doPost`)
   - 앱 내 모달에서 `Code.gs` 원클릭 복사(`Click to Copy`) 제공
   - 웹 앱 URL 입력 시 자동 실시간 동기화 (미연동 시에도 `localStorage`를 통해 안전하게 작동)

## 📋 구글 시트 연동 가이드 (Code.gs)

별도의 백엔드 서버나 유료 결제 없이 무료 구글 스프레드시트에 저장됩니다.

1. [Google 스프레드시트](https://sheets.new)에서 새 시트를 생성합니다.
2. 상단 메뉴의 **[확장 프로그램] → [Apps Script]**를 클릭합니다.
3. 기존 코드를 모두 지우고 웹앱의 **[구글 시트 연동 설정]** 모달에서 복사한 `Code.gs` 코드를 붙여넣고 저장(`Ctrl+S`)합니다.
4. 우측 상단 **[배포] → [새 배포]**를 클릭합니다.
   - 유형: **웹 앱(Web App)**
   - 다음 사용자로 실행: **나(Me)**
   - 액세스 권한: **모든 사용자(Anyone)** *(중요: 학생 태블릿 로그인이 필요 없도록 설정)*
5. 발급된 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사하여 앱 내 **[구글 시트 연동 설정]** 입력창에 넣고 **[연동 테스트 및 저장]**을 누르면 완료됩니다.

## 🚀 Vercel 배포 방법

1. 코드를 본인의 **GitHub 저장소**에 Push합니다.
2. [Vercel](https://vercel.com)에 로그인 후 **[Add New Project]**에서 해당 GitHub 레포지토리를 선택합니다.
3. 기본 설정(Framework Preset: Vite, Build Command: `npm run build`, Output Directory: `dist`) 그대로 **[Deploy]**를 누르면 1분 내로 배포가 완료됩니다!
